# Hello World · First GitHub Pages Site

This is a small static website from the GitHub Pages starter tutorial. The page displays a welcome message and an animated Octocat. It is an example of how an HTML page, a CSS file, and an image work together on a static site.

## Preview locally

Open [`index.html`](index.html) in your browser. There is no build step or backend. The Octocat image is loaded from GitHub's Octodex, so it needs an internet connection.

| File | Purpose |
| --- | --- |
| [`index.html`](index.html) | The welcome message, page title, and Octocat image reference. |
| [`styles.css`](styles.css) | Layout, spacing, and typography. |
| [`images/`](images/) | An image from the original GitHub Pages tutorial. |

## Customize or publish

Change the welcome text in `index.html` and the visual styling in `styles.css` to make the page your own. The repository is a GitHub Pages starter. If you want a public URL, enable Pages for the repository and select the branch and folder that contain `index.html`. See the [GitHub Pages quickstart](https://docs.github.com/en/pages/quickstart).
